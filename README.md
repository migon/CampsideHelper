# Campside Helper

**Campside Helper** is a lightweight, zero-configuration addon designed for the **WoW Forever** camping system. It enhances your gameplay by showing exactly what buffs each profession campsite object provides directly in the 3D world tooltip!

### ✨ Features
* **In-World Tooltips:** Hover over any placed campsite object (like a Mana Well, Camp Tent, or Sharpening Wheel) in the world, and the tooltip will display exactly what buff it gives.
* **Dynamic Level Scaling:** The addon reads your character's current level and calculates the accurate buff value you will receive (e.g., accurately scaling Stamina or Intellect based on your level).
* **Exclusive Buff Warnings:** Never accidentally overlap buffs again! The tooltip clearly warns you in orange text if a campsite buff is mutually exclusive with standard class buffs (such as *Blessing of Kings*, *Mark of the Wild*, or *Arcane Intellect*).
* **Smart Detection:** The addon only modifies the tooltip for objects placed in the 3D world. It intentionally ignores these items in your bags to avoid duplicating the game's default item descriptions.

### ⚙️ How to Use
There is no setup required. Simply install the addon into your `Interface\AddOns` folder, log into the game, and you're good to go! A quick green confirmation message will appear in your chat when the addon loads successfully.
